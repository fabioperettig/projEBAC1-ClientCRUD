# Ebac project 001 – CRUD system

A Java-based user management system featuring a graphical interface via Swing. It provides full CRUD capabilities, allowing admins to register, search, edit, and remove user data. The project implements the DAO (Data Access Object) pattern to demonstrate decoupled database logic in Java.
